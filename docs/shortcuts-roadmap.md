# 普通模式快捷功能候选

已采纳并实现：M 标记视图、? 居中帮助、1/2/3 直接调速。以下其余条目为候选存档，用户暂不采纳，未添加绑定。

| 优先级 | 候选键位 | 功能 | 操作收益与边界 |
| --- | --- | --- | --- |
| 高 | `x` | 左键双击 | 打开文件、选词，一键完成两次点击；保留 Enter 单击 |
| 高 | `Shift+hjkl` | 每次移动 1 个逻辑像素 | 最后一点精调可直接完成，不必切速度或再开网格；适用于 Normal 和 Visual |
| 高 | `u` / `Ctrl+r` | 跳转历史后退 / 前进 | 连续 f、mark、切屏后逐步返回；历史仅在内存中，区别于现有 `''` 两点交换 |
| 高 | `M` | mark 位置视图 | 各屏幕显示落点与字母，按字母跳转；不显示额外说明面板 |
| 中 | `r` / `t` | 右键 / 中键 | 常用鼠标按钮改成单键；r 延续右键后进入 Select 的行为，原组合键仍可用 |
| 中 | `q` / `e` | 按住向上 / 向下滚动 | 普通模式无需一直按住 Alt；Select 中 q 继续用于退出菜单 |
| 中 | `Shift+Space` | 切换到上一块显示器 | 与现有 Space 下一屏配对；仅在普通模式生效，选屏后居中 |
| 中 | `1` / `2` / `3` | 直接选择快 / 中 / 慢 | 从任意当前速度一步切到目标档位 |
| 中 | `y` / `p` | 复制 / 粘贴 | 完成鼠标选区后直接发送 Ctrl+C / Ctrl+V；作用于当前键盘焦点窗口 |
| 中 | `w` / `b` | 鼠标前进 / 后退按钮 | 浏览器、文件管理器等支持侧键的应用可使用；由应用解释事件 |
| 低 | `.` | 重复上次点击或滚动 | 在当前位置重复离散鼠标动作，省去重复键组合 |
| 低 | `?` | 当前模式快捷键速查 | 只在主动请求时展示，Esc 收起，帮助发现功能 |

当前只加入 M、?、1/2/3；其他功能保持候选状态。

若未来采用 `20l` 这样的数字距离前缀，就应重新考虑 1/2/3 的即时速度绑定，避免输入歧义。跳转历史应按显示器名称和逻辑相对位置记录；新跳转清除前进分支，布局变化时拒绝跳到不可用显示器。自动重复按键不应让双击或历史跳转失控。

网格字母应始终与实际落点一致，使用中心文字；快捷功能不需要增加常驻面板或改变系统光标。

另有待讨论的区块步进方案：普通模式 b / e 按 5×5 的 a–y 编码顺序跳到上一块 / 下一块中心。以当前指针所在区块为起点，f/Tab 内继续将 b、e 作为直接选择字母。跨行的较大横向位移需要实测；目前没有实现，也没有为 b/e 绑定浏览器历史动作。
